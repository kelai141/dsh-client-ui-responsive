# 拖动对话到右侧栏

左侧会话行或子代理列表项长按约 400ms 后，屏幕右缘显示蓝色接收区。拖入并松手即可侧开对话，右栏自动展开，主对话保持原位。普通点击、滚动与原有会话排序继续使用原路径。

空间较窄时侧开会自动收起左侧导航，给主对话与右栏留出位置。等待布局及原生宽度测量更新后再打开资源；期间切换主对话或卸载插件会取消待处理操作。横屏沿用 DSH 的两个右侧面板上限。空间不足或面板已满时使用标签页。竖屏只显示当前面板正文，两个分组的原生标签仍可切换；旋转回横屏恢复并排，保留分组及会话状态。

普通对话通过 conversation 资源持有独立 SessionReference。关闭标签或卸载资源时释放引用，不调用主区域的会话导航。子代理以运行时目录的完整行序、层级与标签核对弹窗条目，保留直接父会话地址及模式，复用同一资源入口。目录不一致时不猜测身份。重复拖入由原生资源去重处理。

拖入前先把排序拖动结算为源行无操作，再调用侧开入口。取消、多指、移出接收区或组件卸载均清理拖动状态与蓝区。接收区贯穿屏幕高度，没有描边和上下边界。淡蓝雾光从右向左渐隐，轻度毛玻璃随渐隐遮罩融入界面；白色文案为「松开于侧边栏打开」。拖入时增强反馈，退出时淡出。右侧面板只在边缘增加低强度光晕和窄幅毛玻璃，正文与输入框保持清晰。动效尊重系统减少动态效果设置。

开发验证记录见 PR；热推验证仅覆盖设备运行树，不代表最终 APK 验收。发版前需重新构建并验收实际 APK。
